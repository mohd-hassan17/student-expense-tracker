# Student Expense & Budget Tracker

A modern student budgeting dashboard built with Next.js, TypeScript, and shadcn UI. It helps users add income and expenses, review recent transactions, and monitor total income, total expenses, and net balance in one responsive interface.

## Setup

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser to view the app.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn UI
- localStorage for client-side persistence
